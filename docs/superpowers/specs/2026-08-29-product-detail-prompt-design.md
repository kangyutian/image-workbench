# 商品细节特写提示词设计

## 目标

优化商品套图中的“产品细节特写图”，让模型稳定生成服装某一个局部的详情页特写，而不是整件服装或多个部位的组合图。

## 已确认的行为

- 只修改 `product-detail` 默认提示词，其他套图画面保持不变。
- 从用户上传的服装产品图中选择一个最能体现卖点的局部，例如领口、肩带、面料纹理、印花、缝线、纽扣、袖口、腰头或下摆。
- 一张图片只展示一个局部，采用近距离商品摄影/微距构图，让局部成为画面主体。
- 严格以用户上传的服装图为唯一产品来源，保持颜色、结构、材质、纹理和工艺真实，不新增不存在的设计。
- 禁止真人、人体、衣架、整件服装、多个部位拼图、分格排版、文字、logo 和水印。
- 保留真实布料厚度、纹理、缝线、细小褶皱、柔和高光和阴影。
- 产品细节图不追加人物皮肤描述，避免模型生成皮肤或人体特写。
- 未上传自定义背景图时，使用“浅灰偏白色无缝摄影棚背景”；上传自定义背景后，继续使用统一自定义背景。

## 实现边界

- 不新增接口、数据结构或任务槽位。
- 不改变产品套图的输出数量、文件名、队列和下载逻辑。
- 通过单元测试锁定单局部特写、排除人体/拼图，以及默认/自定义背景分支。
