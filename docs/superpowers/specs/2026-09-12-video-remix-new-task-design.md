# 视频再生新建任务入口设计

## 目标

解决视频再生页面刷新后总是停留在最近项目、下拉框里的“新建视频再生项目”无法实际新建的问题。

## 方案

- 刷新行为保持现状：加载并选中最近的已保存项目，避免用户误丢未完成脚本或生成进度。
- 项目选择器的“新建视频再生项目”变为可用动作，选择后清空当前项目、草稿、已选视频及时长，回到第一步上传界面。
- 页面标题区域增加“新建任务”按钮，和选择器使用同一个清空逻辑。
- 新建动作只重置前端状态，不调用创建项目 API；用户上传视频并点击“开始智能分析”后才创建后端项目，因此不会产生空任务。
- 旧项目继续保存在服务器上，可通过项目选择器重新打开。

## 验收标准

1. 页面源码暴露“新建任务”操作和可复用的新建状态处理函数。
2. 项目选择器选择 `new` 时会调用新建状态处理函数，而不是忽略选择。
3. 新建状态包含 `project`、`draftProject`、源视频文件及时长、错误和忙碌状态的清理，并恢复默认标题与模型设置。
4. 既有视频再生流程和后端接口不变。
