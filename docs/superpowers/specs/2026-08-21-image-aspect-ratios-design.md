# 图片生成比例补全设计

## 目标

将图片创作界面补全为 WaveSpeed GPT Image 2 API 支持的比例预设，并保证前端选项与后端校验一致。

## 范围

- 图片创作全局设置和图片任务卡共用同一套比例选项。
- 支持以下 15 个比例：`1:1`、`1:2`、`2:1`、`1:3`、`3:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`9:21`、`21:9`。
- 后端图片生成请求只接受上述白名单比例，非法值回退到该模型的第一个可用比例。
- 现有视频、产品套图、抠图和印花提取比例逻辑不改。

## 交互

- 保持现有下拉选择交互，不增加任意宽高输入。
- 现有默认比例和任务创建流程保持不变；只扩展可选项。
- 模型专属比例限制仍由现有 `aspectOptionsFor` 逻辑决定；本次补全 Image 2 使用的通用比例列表。

## 实现边界

- 在前端集中维护完整比例列表，避免全局设置和任务卡出现不一致。
- 在服务端为 Image 2 请求增加与前端一致的白名单，防止直接调用接口提交未支持比例。
- 为比例列表/校验添加自动化测试，覆盖完整列表和非法值处理。

## 验收标准

1. 图片创作下拉框可以看到并选择全部 15 个比例。
2. 创建图片任务时所选比例原样传给 Image 2 请求。
3. 非法比例不会发送给 WaveSpeed，而是被安全归一化。
4. 现有图片、视频、产品套图、抠图和印花提取功能的测试与构建不回归。
